# 🍰 Dessert Restaurant

A responsive dessert ordering application built with **React** and **Tailwind CSS**.  
Users can browse a list of desserts, add them to a cart, adjust quantities, and confirm their order—with real-time cart totals and an order confirmation modal.

## ✅ Features

- Display desserts with name, image, category, and price
- Add items to the cart with quantity controls
- Increase and decrease item quantities
- Remove items from the cart
- Live cart summary including:
  - Total items
  - Total price
- Order confirmation modal with purchased items and total
- Start a new order after confirmation
- Fully responsive layout for mobile and desktop

---

## 🧠 What I Learned

- Managing global state using **React Context API** and **useReducer**
- Designing reducers around business actions such as `ADD_TO_CART`, `REMOVE_FROM_CART`, and `PLACE_ORDER`
- Computing derived values (total items and total price) using JavaScript's `reduce()` method
- Building reusable and modular React components
- Handling immutable state updates
- Creating responsive layouts with Tailwind CSS
- Implementing modal overlays and conditional rendering
